# lumo iOS — аудит

SwiftUI, JavaScriptCore, iPhone15Pro, минимум iOS26. Сначала README.md и
CODE-MAP.md. В полном workspace также ../../FINAL-AUDIT.md и
../../outputs/BUILD-STATUS.md. Исторические CSS/Manrope/dock-правила веба
не относятся к нативному UI.

- Деньги в целых копейках, журнал — источник истины. Не ослаблять инварианты.
- `Vendor/Finance` копируется из соседнего finance/js штатным bundle-engine;
  generated Resources/finance-engine.js и engine-manifest.json не править руками.
- Нативный store включает strictEnvelopeBalances; исторический API веба по
  умолчанию допускает старый перерасход. Не удалять эту совместимость молча.
- Тесты только на вымышленных данных, новом симуляторе/отдельном Chrome-профиле.
  LUMO_DEMO/LUMO_FX_TEST работают только в simulator, не на телефоне владельца.
- Не публиковать на fluxprod.xyz, не включать Pages, не использовать fluxprod.
  CI только бесплатная в согласованном открытом ivan495ui/lumo-ios, без секретов.
- Сертификат не отправлять в CI, Bundle ID не менять под provisioning.
  Владелец сам подписывает IPA в ESign, сохраняя идентификатор прежней установки.
- Настоящие iCloud/Face ID и установка последней IPA пока требуют проверки
  владельцем. Нулевая вероятность потери не обещается; копия — не синхронизация.
- Дизайн согласован, иконку делает другой исполнитель без imagegen.
  В конвертах и основном балансе ≈ скрыт только при отображении; пересчёт сохранён.
- Для финального аудита сначала короткий план и отчёт с доказательствами.
  Не менять код/не публиковать только ради косметики; не повторять дорогие
  проверки без причины. Файлы редактировать через patch/edit, не PowerShell.
