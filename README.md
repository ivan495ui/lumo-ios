# lumo · iOS

Нативная версия для iPhone 15 Pro / iOS 26 и новее. Интерфейс — SwiftUI,
системные TabView, NavigationStack, List, Form, sheet и Swift Charts.
HTML, CSS, WKWebView и веб-панели в приложении нет.

## Финансовая логика

`Vendor/Finance` — точная копия проверенных четырёх модулей веб-версии.
`node tools/bundle-engine.mjs` собирает их без изменения расчётов в локальный
ресурс JavaScriptCore. SHA-256 исходников лежат в `engine-manifest.json`.
Транспорт передаёт только JSON, разрешает перечисленные команды и не выполняет
пользовательский текст как код. Деньги остаются целыми копейками.

Карта + наличные = конверты + доступный налоговый резерв + свободно.
Крипта отображается отдельно; включение её в общий баланс не меняет конверты.
Новая установка: BYN, 32 / 32 / остаток, налоговый резерв выключен.
Изменение долей касается будущих доходов; накопленное распределяется отдельно
с предварительным расчётом и подтверждением.

## Данные

JSON находится в Application Support/lumo, сохраняется атомарно. Перед записью
сохраняется предыдущая исправная версия; при ошибке диска изменения в памяти
откатываются. Повреждённый основной файл читается из backup, повреждение обеих
копий не создаёт молча пустой журнал. Перед восстановлением повреждённые файлы
сохраняются отдельно в Recovery-UUID.

Импорт совместим с экспортом веб-версии, перед заменой показывает количество
операций и баланс. Приложение не обращается к Telegram CloudStorage и не меняет
старые данные. Экспортируй JSON из Telegram **на телефоне с операциями**, затем
импортируй в lumo. Между устройствами синхронизации в этой версии нет.
Сертификаты и реальные финансовые данные не входят в исходники или CI.

## Изменения 2.1

Валюта отображения отделена от валюты учёта. USD/RUB пересчитываются по дневному
курсу НБРБ с датой и локальным кэшем; без курса показывается исходная валюта.
Переключение вида не изменяет чисел журнала. Формы всегда явно указывают валюту
учёта. Старые записи с иной подписью требуют подтверждения фактических единиц.
На конвертах округляются только отображаемые суммы; копейки сохраняются.

USDT: отдельные записи получения, отправки и вывода в обычные деньги; количество
отделено от ручного курса. Приложение ведёт учёт, а не отправляет криптовалюту.

Можно один раз подключить папку в iCloud Drive через системный выбор «Файлов».
После локального сохранения защищённая очередь автоматически обновляет текущую
и предыдущую зашифрованные копии. AES-256-GCM, PBKDF2-HMAC-SHA256; пароль только
в Keychain этого устройства. Пароль восстановления нужно сохранить отдельно.
Статус записи в папку и подтверждение выгрузки iCloud различаются. Нулевая
вероятность потери данных не обещается; сбой копирования виден в настройках.
Опциональная защита Face ID/кодом скрывает содержимое при уходе в фон.

Иконка собрана из SVG и отрендерена в изолированном браузере; исходник находится
в `Design/LumoIcon.svg`. Генеративные изображения для неё не использовались.

## Проверка и сборка на Mac

```sh
node tools/bundle-engine.mjs
node --test tests/bridge.test.mjs
swift test
brew install xcodegen # если ещё не установлен
xcodegen generate
xcodebuild -project lumo.xcodeproj -scheme lumo -configuration Release \
  -sdk iphoneos -destination 'generic/platform=iOS' \
  -derivedDataPath build/device CODE_SIGNING_ALLOWED=NO build
bash tools/simulator-check.sh
```

`.github/workflows/ios.yml` — ручная ограниченная 30 минутами сборка на облачном
Mac, без Pages и без расписания. Проверяет JS-транспорт, настоящую JavaScriptCore,
компиляцию для устройства и UI в новом симуляторе. При успехе отдаёт неподписанную
IPA и скриншоты. Она требует отдельной подписи действующим сертификатом и
профилем устройства; наличие ZIP/IPA не подтверждает возможность установки.

Режим `full` выполняет все проверки; `design` собирает и проверяет симулятор
для примерки интерфейса, `device` отдельно упаковывает неподписанную IPA.
Изменение финансовых модулей требует `full`. Все режимы используют только
бесплатный стандартный runner открытого репозитория.

`LUMO_DEMO=1` наполняет только отдельный контейнер **симулятора** вымышленными
данными. Этот код исключён из сборки для реального устройства.
